🏫 Simulator "Logika Denah" — Gedung Sekolah

Spesialis tata letak ruangan, arah mata angin, jarak/rute, dan proporsi luas. Bacalah denah, lalu jawab 3 pertanyaan bertingkat.

📐 Skenario Denah

Sebuah gedung sekolah satu lantai berbentuk persegi panjang 8 × 6 satuan grid. Setiap satuan grid mewakili 5 meter. Arah Utara di bagian atas. Denah dibagi menjadi beberapa ruangan berikut:

        U
        ↑
  ┌───┬───┬───┬───┬───┬───┬───┬───┐
  │   │   │   │   │   │   │   │   │  baris 1 (paling utara)
  ├───┼───┼───┼───┼───┼───┼───┼───┤
  │   │   │   │   │   │   │   │   │  baris 2
  ├───┼───┼───┼───┼───┼───┼───┼───┤
  │   │   │   │   │   │   │   │   │  baris 3
  ├───┼───┼───┼───┼───┼───┼───┼───┤
  │   │   │   │   │   │   │   │   │  baris 4
  ├───┼───┼───┼───┼───┼───┼───┼───┤
  │   │   │   │   │   │   │   │   │  baris 5
  ├───┼───┼───┼───┼───┼───┼───┼───┤
  │   │   │   │   │   │   │   │   │  baris 6 (paling selatan)
  └───┴───┴───┴───┴───┴───┴───┴───┘
   1   2   3   4   5   6   7   8   ← kolom (Barat → Timur)
📏 1 grid = 5 m ⬆️ Utara = atas ➡️ Timur = kanan

Aturan Tata Letak (WAJIB dipenuhi):

  1. Perpustakaan (P) menempati 2×2 grid di sudut Barat Laut gedung (menempel dinding utara & barat).
  2. Kantin (K) menempati 2×2 grid di sudut Tenggara gedung (menempel dinding timur & selatan).
  3. Lab Komputer (L) menempati 2×2 grid, letaknya tepat di sebelah timur Perpustakaan (menempel sisi timur P, sejajar horizontal).
  4. Ruang Guru (G) menempati 1×1 grid, berada tepat di sebelah selatan Lab Komputer.
  5. Aula (A) menempati 3×2 grid (lebar 3 kolom, tinggi 2 baris) yang menempel dinding selatan gedung, dan seluruh bagiannya berada di sebelah barat Kantin.
  6. Sisa grid yang belum terpakai menjadi Koridor (·).

❓ Pertanyaan Bertingkat

Tulis jawabanmu di kotak. Gunakan format sederhana (contoh: baris 3 kolom 5, 20 m, 30 m²).

  1. [Level 1 — Logika Posisi & Arah]
    Tentukan koordinat grid (baris, kolom) tempat Ruang Guru (G) berada. Jelaskan pula posisi G terhadap Perpustakaan (P): apakah G di sebelah timur, barat, utara, atau selatan P?
  2. [Level 2 — Jarak Terpendek]
    Seorang siswa berdiri di titik tengah pintu Lab Komputer (L) sisi selatan, lalu berjalan lurus menyusuri koridor menuju titik tengah pintu Kantin (K) sisi barat. Jika ia hanya boleh bergerak horizontal lalu vertikal (menyusuri grid, bukan diagonal), berapa jarak terpendek (dalam meter) yang ditempuh? Petunjuk: hitung selisih grid lalu kalikan 5 m.
  3. [Level 3 — Luas & Proporsi]
    Hitung total luas lantai (m²) yang ditempati oleh Perpustakaan (P), Lab Komputer (L), dan Aula (A) jika digabung. Lalu tentukan persentase luas gabungan ketiganya terhadap luas seluruh gedung (bulatkan ke bilangan bulat terdekat).
